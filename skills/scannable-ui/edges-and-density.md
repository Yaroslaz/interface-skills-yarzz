# Края и плотность: рецепты

## Найти края

Края — это не только границы контейнера. Это любая прямая, которую видит глаз:

| Край | Пример |
| --- | --- |
| Внешний край контейнера | Левый край карточки, правый край строки таблицы |
| Нижний край блока | Низ аватара с именем — на него встаёт следующий ряд |
| Линия строки | Каждый пункт чек-листа — край для следующего |
| Колонка значений | Правый край цен на чеке, колонка чисел в таблице |
| Созданный край | Кнопки и аватар, выровненные в одну линию, — новый «верх» для содержимого ниже |

Почти любой компактный интерфейс — поле чата, карточка канбана, боковая панель — держится на том, что **каждый элемент касается двух и более краёв**.

## Выравнивание

- Текст — к началу строки, числа — к концу (`text-align: end`), моноширинные цифры (`font-variant-numeric: tabular-nums`).
- По центру — только то, что не нужно читать построчно: пустые состояния, коды, иллюстрации.
- Одна величина отступа на уровень вложенности; не вводи новый отступ для каждого блока.
- Логические свойства (`margin-inline-start`, `inset-inline-end`) вместо `left/right` там, где интерфейс может зеркалиться.

```css
/* Чек: два края, никаких разделителей */
.receipt-row {
  display: flex;
  justify-content: space-between;
  gap: 16px;
}
.receipt-row > :last-child {
  text-align: end;
  font-variant-numeric: tabular-nums;
}
```

## Создать край вместо пустоты

```text
Плохо:  [аватар] Имя                  ← справа пусто, «добавим кнопок»
        [Кнопка][Кнопка][Кнопка][⋮]   ← кнопки не касаются ни одного края

Лучше:  [аватар] Имя         [Кнопка] ← кнопка и аватар на одной линии:
        ─────────────────────────────    это новый верхний край
        Содержимое встаёт на эту линию
```

## Плотность и различение

1. **Не добавляй воздух первым.** Он делает экран длиннее, а читать его не легче.
2. **Различи типы содержимого:** люди — аватарами, категории — чипами, ссылки — цветом и подчёркиванием, статусы — точкой с подписью.
3. **Сгруппируй по вопросу пользователя:** задачи — по сроку, студенты — по статусу работы, вопросы — по теме.
4. **Отдели группы пространством:** внутри группы `8px` — между группами `16px` и больше. Линии — только там, где пространства не хватает (таблицы, длинные списки настроек), и то тонкие и бледные.

## Широкие экраны

Строка во всю ширину монитора теряет края: глаз не может перейти от названия к значению. Ограничь ширину чтения (`max-width: 65ch` для текста), а связанные значения ставь рядом, а не по краям экрана.

## Проверки

- Закрой глаза наполовину (или размой скриншот): видны ли вертикали, на которых стоит содержимое? Если вместо них «шум» — краёв не хватает.
- Найди элемент, который не касается ни одного края. Это кандидат на перенос или на создание нового края.
- Сосчитай одинаковые по виду строки подряд. Больше пяти-семи — их нужно различить или сгруппировать.
