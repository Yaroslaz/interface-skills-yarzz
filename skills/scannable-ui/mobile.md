# Плотный кабинет на телефоне

Правила проверены на кабинете преподавателя (дисциплины, сессии, ведомости, мониторинг): десяток таблиц шириной 800–1200px, фильтры, формы в модальных окнах. Студенческая часть (прохождение теста) сознательно не адаптировалась — у неё свои требования.

Точки перелома: **62em** — боковая навигация уступает нижнему меню; **48em** — таблицы становятся строками, окна — шторками.

## Нижнее меню-остров

- 4 главных раздела + «Ещё». «Ещё» открывает полную навигацию (разделы и учётную запись) — ту же, что на широком экране.
- Остров не касается краёв экрана: отступ `10–12px`, учитывает `env(safe-area-inset-bottom)`.
- Высота около `60px`, пункт — значок `22px` над подписью `11px`. Подписи короткие: «Сессии», а не «Тестовые сессии». Обрезанная подпись читается хуже короткой.
- Текущий раздел — единственный цветной пункт (фон + цвет), остальные серые. Если открыт раздел не из главных — подсвечивается «Ещё», иначе меню не показывает, где ты.
- `aria-current="page"` у текущей ссылки, у «Ещё» — `aria-haspopup="dialog"` и `aria-expanded`.
- Радиус концентричен: радиус острова = радиус пункта + отступ (22 = 16 + 6).
- Содержимое кончается **над** меню (нижний отступ каркаса = высота меню + зазоры), а не прячется под ним. Всплывающие уведомления поднимаются над меню.
- Бургер в шапке на этих ширинах убирается — две двери в одну комнату путают.

## Таблицы → строки в две линии

Таблица не листается вбок никогда. Разметку не переписывают — CSS перекладывает ту же таблицу в столбик, поэтому флажки, ссылки, меню и щелчок по строке продолжают работать.

```text
[☐] Название записи (одна строка, многоточие)         [⋮]
    Подпись значение   Подпись значение   ● Статус
```

- **Название** — первой строкой во всю ширину, в одну строку. Подстрочник (семестр, шаблон, учебный год) на телефоне скрыт — он есть в записи.
- **Главные колонки** — 2–3 значения одной строкой «подпись значение» (подпись мельче и серая). Какие главные — решает таблица: то, ради чего открывают список («Проверить», «Не сдали», «Результат»). Остальные колонки скрыты — запись открывается нажатием на строку.
- **Флажок** — у левого края строки, **меню ⋮** — в правом верхнем углу: у всех строк одни и те же края.
- Флажок «Отметить все» остаётся видимым над списком — иначе на телефоне пропадёт массовое выделение.
- **Статус** — точка с текстом без подписи «Статус:» — узнаётся сам.
- **Ноль и прочерк — серые**: ненулевые значения находятся среди них сразу.
- Шапка таблицы скрыта визуально, но остаётся для скринридера.
- Высота строки — около 50–70px.

Реализация, которая работает с любой таблицей без переписывания:

1. Небольшой модуль проставляет каждой ячейке `data-label` из текста заголовка колонки и роли: `data-cell="title" | "actions"`, `data-mobile-hidden` для неглавных колонок, `data-quiet` для нулей. Главные колонки таблица помечает в заголовке: `<th data-mobile="primary">`. Без отметок — две первые.
2. Наблюдатель (`MutationObserver`) обновляет атрибуты, когда таблица перерисовывается, — только пока экран узкий.
3. CSS под `@media (max-width: 48em)`: `tr` — `display: flex; flex-wrap: wrap`, ячейки — `inline-flex` с `::before { content: attr(data-label) }`, флажок и меню — `position: absolute`.

Подводные камни:

- Если у ячеек уже есть `::before` (например, вертикальные разделители колонок), сбрось у подписи `position`, `inset`, `width`, `background` — иначе подпись ляжет поверх значения.
- Правила скрытия (`display: none`) делай `!important`: любое более позднее правило с `display` вернёт колонку.
- Сбрось `min-width`, ширины `colgroup`, фиксированную высоту строк и `position: sticky` у первой колонки.
- Таблицы в неактивных вкладках остаются в разметке — проверяй видимую.

## Окна → шторки

- `max-width: 48em`: окно прижато к низу, во всю ширину, скругление только сверху (`20px`), максимум `100dvh - 24px` — сверху остаётся полоса затемнения, по которой окно закрывается.
- Подвал с кнопками закреплён внизу шторки, тело прокручивается, `overscroll-behavior: contain`.
- Анимация открытия — короткая и выключается при `prefers-reduced-motion`.

## Шапка раздела

- Пояснение под заголовком верхнего раздела («Учебные предметы, к которым привязаны…») — в значке ⓘ на любой ширине: оно нужно один раз и отодвигает список на полэкрана.
- Заголовок `1.3rem`, без минимальной высоты строки шапки.
- Кнопки — одной строкой: главная (залитая) растянута, второстепенные со значком слева — только значком `36px` с `aria-label`; редкие («Импорт», «Найти в расписании») — в меню «⋯». Кнопка без значка («Ведомость →») остаётся текстом.
- Вкладки в шапке — равной ширины, без переноса, подпись с многоточием; счётчики во вкладке не должны распирать шапку (`overflow: hidden` у вкладки).
- Плашки-факты записи: технические — скрыты, остальные — без фона, просто значок и текст.
- На вложенном экране подзаголовок содержит данные записи («ИВТ-31 · Итоговый экзамен») — его не скрывают.

## Фильтры

- Строка: поиск (растянут) + кнопка «Фильтры» значком + главное действие. Отборы-селекты на телефоне переезжают во всплывающий блок «Фильтры» — в строке им места нет.
- Кнопка «Сбросить условия» видна, только когда есть что сбрасывать: неактивная кнопка на телефоне — потерянное место.

## Подводные камни Mantine

- Залитая кнопка (вариант по умолчанию) **не получает** `data-variant` — выбирай её через `:not([data-variant])`; кнопка со значком слева — `[data-with-left-section]`.
- Класс самой таблицы — `mantine-Table-table`, а не `mantine-Table`.
- `Tooltip` на касание реагирует только долгим нажатием, а после тапа эмулируется `mouseleave` — для ⓘ бери `Popover`, открывай по `click`, по наведению — только при `pointerType === 'mouse'`.
- `visibleFrom="sm"` / `hiddenFrom="sm"` — граница `48em`, совпадает с переломом таблиц.

## Прокрутка

- Область, которой нечего прокручивать по вертикали (например, горизонтальная обёртка таблицы), не должна иметь `overscroll-behavior: contain` — иначе колесо и свайп над ней «застревают» и страница не листается.
- `contain` — только у областей, которые сами прокручиваются: модальные окна, выпадающие списки, боковые панели.

## Проверки

- 320, 390 и 768px: нет горизонтальной прокрутки ни у страницы, ни у таблиц.
- Высота строки списка ≤ 84px.
- Нижний край острова содержимого выше верхнего края нижнего меню.
- Модальное окно на 390px занимает всю ширину и касается нижнего края.
- Свайп по таблице прокручивает страницу.
- Шапка раздела на 320px не шире экрана (вкладки со счётчиками, кнопки).
